## How this repo works

One integrator agent talks to the course API — slowly, reading every word.
Each solved challenge becomes an offline replica with deterministic scoring,
and the replica goes to the bench: nine models, three vendors × three tiers,
running the same brief in parallel worktrees. Results are numbers, not vibes.
