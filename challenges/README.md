# challenges

One folder per challenge, filled while it is played live:

- `log.md` — every request body sent and every reply received, exactly
- `artifacts/` — anything the challenge produced or required
- `debrief.md` — the debrief as filed with the course

No spoilers policy: course challenge content (descriptions, start points,
accepted answers) and worker briefs live **outside this public tree**, in the
operator's private artifact store. This folder holds only the public working
record. Logs and artifacts with course material are gitignored.
