# Benchmark policy — planned work

The comparison unit is **one plan, one operator and that operator's fleet**.
There may be one or many plans; each plan is compared across nine model
configurations. A 6 × 9 formation names 54 cells, not 54 proven completions.

Within one plan, every configuration must receive equivalent inputs and the same
judging rules. Metrics need reproducible scripts and retained evidence, not
worker self-assessments. The official course MCP must not be available to bench
workers.

No replicas, graders or comparative results are published here yet. Course
inputs, receipts, accepted answers and course-dependent replicas stay private
unless redistribution rights are explicitly established. Public examples must
use independently authored synthetic material with clear provenance.
