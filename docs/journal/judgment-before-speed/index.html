Editing starts with a comparison

2026-10-29 · Maciej + agents · 1 min read · S01E01 · Updated 2026-10-29

When an agent returns a shorter, smoother text, it is tempting to read only the new version. In our editing work, we returned to both. A sentence could sound better while dropping the qualification that gave the original its meaning.

Maciej decided what to remove. The agent placed the proposed edit beside the source and showed the actual differences. Instead of a general request for approval, this made the conversation specific: is this information unnecessary, or is it simply inconvenient to shorten?

That review has two speeds. First, read the whole piece to understand its purpose. Then inspect individual changes. A character count describes the size of an edit; it cannot decide whether the text still says the same thing.

We use the same approach in The Journal. A headline and excerpt should invite someone to read, without promising more than the article delivers. An edit should improve the account, not quietly give it a better outcome.
