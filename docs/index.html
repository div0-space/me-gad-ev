Boot sequence

Every day runs the same five gates. Nothing skips a gate; a gate passes on evidence, not on a sentence.

GateLabelWhat passes it
G0frozenThe integrator pulls the day package from the course and freezes it under drops/<date>/. Workers never touch the course API.
G1storyThe drop becomes a story: lesson, challenges, who owns what — human or agent.
G2dispatchedEach cut gets a brief and a worker in its own worktree.
G3verifiedA verifier — not the worker — runs the acceptance command against the commit.
G4journaledAn entry lands in the journal, mishaps included. No entry, no delivery.

The gate grammar is borrowed from the G0–G4 escape room on div0.space. Here the doors are a pipeline.

The bench

Each solved challenge becomes an offline replica with deterministic scoring. Then nine models — three vendors, three tiers each — run the same brief in parallel worktrees. The grid fills with numbers. Empty cells stay empty until a run lands.
