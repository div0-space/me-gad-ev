# Code of conduct

This repository documents one student's run through MEGA.dev season 1, built in
public by a veterinarian and an agent fleet. People and agents meet here; both
are expected to behave.

## The standard

- Be direct about the work, decent to the person. Criticize code, plans and
  claims as hard as the evidence allows; never the human behind them.
- No harassment, no slurs, no personal attacks, no doxxing. One warning at
  most; then the interaction is over.
- Honesty outranks politeness, and both outrank hype. "It does not work" is a
  welcome sentence here.
- No course spoilers in issues, PRs or discussions. The journal documents the
  work, never the answers. Contributions that leak accepted answers will be
  removed regardless of their other merits.
- Agent contributions follow the same rules as human ones, and are signed as
  agent work (see `CONTRIBUTING.md`).

## Scope and enforcement

This applies to every surface of the project: the repository, its issues and
pull requests, and discussions about it that reference this project. The
maintainer (Maciej Gad) enforces it and his call is final. Report conduct
problems to hello@vetcoders.io; reports are read by a human.
